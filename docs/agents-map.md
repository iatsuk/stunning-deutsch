# Карта переноса `AGENTS.md`

Временный документ для проверки автором: куда переехало каждое предложение прежнего корневого
`AGENTS.md` (коммит `06b3bad`) при разделении инструкций по областям. После проверки его можно
удалить: ни инструкции, ни тест на него не ссылаются.

## Новая структура

```
AGENTS.md                      индекс: правила для всего проекта и таблица «Куда смотреть»
CLAUDE.md                      @AGENTS.md (как раньше)
content/AGENTS.md              уроки A1–B1, страница урока, игры тем
content/assessments/AGENTS.md  входные работы, проверки, пробники (дополняет content/)
scripts/tts/AGENTS.md          озвучка: готовые записи и новая генерация
src/story/AGENTS.md            игра Moin целиком, включая прототип сцен и его движок
<каталог области>/CLAUDE.md    @AGENTS.md
src/{adventure,trainer,case}/CLAUDE.md          @../../content/AGENTS.md
src/{pages,stage,assessment}/CLAUDE.md          + @../../content/assessments/AGENTS.md
```

Claude Code подгружает `CLAUDE.md` каталога, когда читает его файлы; Codex сливает `AGENTS.md` от
корня до рабочего каталога. Код уроков и контролей лежит не в `content/`, поэтому его каталоги
получают только `CLAUDE.md` с импортом файла области: правило остаётся в одном месте. Для Codex,
запущенного из корня, маршрут даёт таблица в корневом `AGENTS.md`.

Отдельного `src/story/scenes/AGENTS.md` нет: движок сцен (`scene.ts`, `SceneView.tsx`,
`ScenePreview.tsx`, `world.ts`) лежит в `src/story/`, а `scenes/01.ts` — внутри него, поэтому один
файл `src/story/AGENTS.md` подгружается для обоих.

## Как проверено

Прежний файл разбит на 138 предложений (пункты списков и абзацы, деление после `.`, `!`, `?`).
137 найдены в новых файлах дословно и каждое ровно в одном файле. Одно (№98) было повтором двух
других правил и объединено с ними. Повторить проверку:

```sh
node --input-type=module <<'JS'
import { execSync } from "node:child_process";
import { readFileSync } from "node:fs";
const old = execSync("git show 06b3bad:AGENTS.md", { encoding: "utf8" });
const now = ["AGENTS.md", "content/AGENTS.md", "content/assessments/AGENTS.md", "scripts/tts/AGENTS.md",
  "src/story/AGENTS.md"].map((f) => readFileSync(f, "utf8"));
const all = old.split("\n").map((l) => l.trim().replace(/^- /, "")).filter((l) => l && !l.startsWith("#"))
  .flatMap((l) => l.split(/(?<=[.!?])\s+(?=[A-ZА-ЯЁ«`*\d])/u));
all.forEach((s, i) => { const n = now.filter((t) => t.includes(s)).length; if (n !== 1) console.log(i + 1, n, s); });
console.log("всего", all.length);
JS
```

Ожидаемый вывод — только №98 с нулём совпадений и «всего 138».

## Что добавлено

Новый текст только связывает области и не меняет правил:

- корневой `AGENTS.md`: абзац об устройстве индекса, заголовки «Общий браузер» и «Инфраструктура
  генерации», ссылка на `scripts/tts/AGENTS.md` в «Озвучке», таблица «Куда смотреть» со сквозными
  случаями;
- в каждом файле области — строка «Область: …» со ссылкой на общие правила;
- `content/assessments/AGENTS.md`: правила `content/AGENTS.md` действуют и для контролей, формат —
  раздел `CONTENT.md` «Входная работа, проверки и пробник»;
- `src/story/AGENTS.md`: правило о двух одинаковых действиях подряд действует и в шагах, и в сценах
  (его уже проверяют `scripts/story.test.mjs` и `scripts/scene.test.mjs`); ссылки на правило о
  множественном числе существительных (`CONTENT.md`, «Слова — `words`», и `A1-PLOT.md`), на
  `scripts/tts/AGENTS.md` и на правило общего браузера;
- `scripts/agents.test.mjs` в `pnpm test`: ссылки индекса существуют, у каждого `AGENTS.md` области
  есть соседний `CLAUDE.md` с `@AGENTS.md`, каждый вложенный `CLAUDE.md` только импортирует файлы
  областей, каждая область названа в индексе, предложение правила не повторяется в двух файлах,
  корень не длиннее 60 строк.
