# Как писать тему

Тема — один файл `content/<уровень>/<NN>-<id>.yaml`. Из него собирается страница: разбор с закреплённой сценой, шпаргалка, дело темы, тренажёр и словарь. Герои, места и сквозной сюжет — в [WORLD.md](WORLD.md). Образец — [content/a1/01-kennenlernen.yaml](content/a1/01-kennenlernen.yaml): прежде чем писать новую тему, прочитайте его целиком.

Проверка без записи файлов и без озвучки:

```sh
node scripts/build-content.mjs --check --only 02-zahlen
```

Сборка с готовыми аудио — `pnpm content`. Для новых или изменённых фраз сначала [экспортируйте манифест и сгенерируйте записи](scripts/tts/README.md). Пока записей нет, текст можно посмотреть на странице через `pnpm draft`: черновая сборка пишет JSON без новых записей и прячет у них кнопку озвучки. Такую сборку не коммитят.

## Формат рассказа

Тема — короткая история, а не параграф учебника. Есть герои, место и повод заговорить. Читатель листает текст слева, а сцена справа показывает то, о чём идёт речь: реплики, карточки слов, таблицу, схему предложения или задание экзамена.

Главы одинаковые во всех темах:

| Глава | id | Что делаем |
|---|---|---|
| Ситуация | `scene` | Один или два диалога, реплики открываются по одной |
| Слова | `words` | Группы слов, по одной группе на фрагмент |
| Грамматика | `grammar` | Таблицы и схемы предложений. Одна мысль — один фрагмент |
| Проверка | `practice` | Вопросы «а как сказать…». Ответ скрыт под кнопкой |
| На экзамене | `exam` | Задание в формате telc и разбор, как его решать |

Ориентиры по объёму: 18–26 фрагментов, 3–5 вопросов, 1–2 диалога по 6–10 реплик, 3–5 групп слов (30–50 слов всего), 2–4 таблицы, 12–16 упражнений.

## Тексты

- `read` — абзац на русском, 45–90 слов. Объясняйте, почему так, сравнивайте с русским, предупреждайте о типичных ошибках. Говорите с читателем на «вы».
- Каждый немецкий фрагмент в русском тексте берите в звёздочки: `*Ich heiße Anna*`. Он будет набран антиквой и выделен цветом. Кавычки вокруг немецкого не нужны. Звёздочки работают в `read`, `point`, `question`, `lede`, `goals`, `title` шага, `why` и в русских колонках таблиц.
- `point` — тезис для шпаргалки, до 120 символов. Обычно это правило плюс пример: `"*wir*, *sie*, *Sie* — как инфинитив"`.
- `question` — вопрос к читателю, до 90 символов. Ответ — в `read` того же фрагмента.
- Немецкий — только того уровня, который вы проходите, и только та грамматика, что уже была в предыдущих темах или вводится в этой (см. маршрут ниже). Готовые фразы вроде *Ich möchte …* можно давать раньше как выражение, не разбирая грамматику.
- Русский: кавычки «ёлочки», буква ё, тире —, числа цифрами.

## Разметка

| Где | Запись | Что получится |
|---|---|---|
| Русский текст | `*Ich bin Anna*` | Немецкий фрагмент |
| Немецкий текст | `wohn+st` | Окончание *st* подсвечено |
| Немецкий текст | `*heiße*` | Слово выделено акцентом |

`+` ставится перед окончанием внутри слова: `komm+e`, `ein+en`, `d+en`. Работает и в русском тексте внутри звёздочек: `*du wohn+st*`.

## Подводные камни YAML

- В записи `{ de: …, ru: … }` и `[a, b, c]` запятая разделяет поля. Если в тексте есть запятая, берите его в кавычки: `{ de: "Danke, gut!", ru: "Спасибо, хорошо!" }`.
- Строку, которая начинается с `*`, тоже берите в кавычки: `point: "*Hallo!* — приветствие"`.
- `: ` (двоеточие с пробелом) внутри строки без кавычек ломает разбор. Тоже кавычки.
- Длинные абзацы пишите через `>-`, внутри них кавычки не нужны.

Проверка ловит эти ошибки: неизвестное поле, лишняя ячейка таблицы, непарная звёздочка.

## Шапка темы

```yaml
id: zahlen                  # латиница, становится адресом страницы
order: 2                    # номер в маршруте уровня
title: Eins, zwei, drei …   # немецкое название
ru: Числа и алфавит         # русское название
lede: >-                    # 2–3 предложения: о чём история и чему научимся
goals: [ … ]                # 3–5 пунктов «Вы научитесь …»

```

## Материалы сцены

### Диалоги — `dialogues`

```yaml
dialogues:
  kurs:
    title: Der erste Kurstag      # по-немецки
    ru: Первый день на курсе
    place: Sprachschule, Leipzig   # необязательно
    people:
      A: { name: Anna, voice: Anna }
      M: { name: Marco, voice: Reed }
    lines:
      - A: Hallo! Ich bin Anna.
        ru: Привет! Я Анна.
```

Первый в `people` говорит слева, остальные справа. Логические голоса Qwen3-TTS 1.7B: женские `Anna`, `Sandy`, `Shelley`, `Flo`; мужские `Reed`, `Eddy`, `Rocko`, `Grandpa`. Имена сохранены для совместимости контента; постоянные образцы находятся в `scripts/tts/voices`.

Герои, их голоса и места — в [WORLD.md](WORLD.md): ученики Дана (`Anna`), Матео (`Reed`) и Элиф (`Flo`), немцы — сотрудники школы, начальник гавани, соседи. Новых персонажей сначала добавьте туда.

### Слова — `words`

```yaml
words:
  person:
    title: Angaben zur Person
    ru: О себе
    items:
      - { de: der Name, ru: имя, pl: Namen }       # мн. ч. без артикля
      - { de: das Obst, ru: фрукты, pl: "-" }      # нет мн. ч.
      - { de: die Eltern, ru: родители, pl: pl }   # только мн. ч.
      - { de: wohnen, ru: жить, note: ich wohne }  # не существительное — без pl
```

Слово с артиклем `der`/`die`/`das` в начале считается существительным, и `pl` у него обязателен. Цвет карточки показывает род. Озвучка произносит и множественное: «der Name, die Namen». `note` — короткая подсказка: форма, пример, особенность.

### Таблицы — `tables`

```yaml
tables:
  sein:
    title: sein
    ru: быть
    head: [Person, sein, Beispiel]
    rows:
      - [ich, bin, Ich bin Anna.]
    ruCols: [2]      # номера колонок на русском, с нуля; по умолчанию все немецкие
    note: Неправильный глагол — формы надо запомнить.
```

### Задания экзамена — `tasks`

У каждого задания `kind`, `part` (часть экзамена), обычно `title` и `situation` по-немецки — как в экзаменационном листе.

| kind | Поля | Что на сцене |
|---|---|---|
| `keywords` | `words`, `sample` | Лист с ключевыми словами (Sprechen 1) и образец ответа |
| `form` | `fields: [{label, value, given}]` | Анкета (Schreiben 1). `given: true` — поле уже заполнено |
| `card` | `theme`, `word` или `picture` (эмодзи), `sample` | Карточка Sprechen 2 (тема + слово) или 3 (картинка) |
| `sign` | `text`, `statement`, `answer: true/false` | Табличка (Lesen 3), утверждение richtig/falsch |
| `message` | `from`, `to`, `subject`, `text`, `points`, `statement`/`answer`, `sample` | Письмо или записка (Lesen 1, Schreiben 2) |
| `listen` | `text` + `voice` или `dialogue`; `question` + `options` + `answer` или `statement` + `answer` | Запись (Hören). `text` звучит одним голосом — для объявлений и автоответчика. `dialogue: id` проигрывает диалог из `dialogues` голосами героев — для разговоров Hören Teil 1; этот диалог не обязан появляться в сцене. Текст виден только после ответа |
| `ads` | `situation`, `options: [{title, text}]` × 2, `answer: 0/1` | Два объявления (Lesen 2) |

Перевод строк в `text` — `\n` или блок `|`. `answer` у вариантов — номер с нуля. `sample` — список немецких строк: образец ответа, каждая озвучивается.

## Фрагменты — `steps`

```yaml
steps:
  - id: treffen          # латиница
    chapter: scene
    title: Первая встреча
    beats:
      - read: >- …
        point: …
        set: { view: dialogue, dialogue: kurs, reveal: 1 }
```

`set` меняет сцену. Всё, что не указано, остаётся от предыдущего фрагмента. Когда меняется `view` или объект на сцене (другой диалог, другая группа слов), `reveal`, `focus` и `solved` сбрасываются: объект показан целиком, без выделения.

`focus` подсвечивает элементы акцентом, а остальные затемняет. Два правила:

- То, что открылось в этом фрагменте, никогда не затемняется: новые реплики диалога и новые строки таблицы, слов или схемы, добавленные через `reveal`. Иначе реплика выглядит так, будто до неё ещё дойдут. Диалог прокручивается к новым репликам, а не к последней.
- Если у фрагмента есть `focus`, в него должно входить всё, что цитирует текст. Проверка предупреждает: «… есть в тексте, но реплика N затемнена / не выделена — добавьте N в focus».

| view | Что указать | reveal | focus |
|---|---|---|---|
| `dialogue` | `dialogue: id` | сколько реплик открыто | номера реплик с нуля |
| `words` | `words: id` | сколько слов открыто | номера слов |
| `table` | `table: id` | сколько строк открыто | номера строк |
| `sentence` | `rows: […]` | — | номера строк схемы |
| `task` | `task: id`, `solved: true` | сколько полей анкеты или строк образца | — |
| `clock` | `time: "15:45"` | — | — |

### Схема предложения — `view: sentence`

Главная визуализация курса: четыре поля немецкого предложения — позиция 1, глагол, середина, конец. Каждая строка `rows` — четыре строки полей, пустое поле — `""`.

```yaml
set:
  view: sentence
  rows:
    - de: [Ich, steh+e, um sieben Uhr, auf.]
      ru: Я встаю в семь часов.
    - de: ["", Steh+st, du um sieben Uhr, auf?]
      ru: Ты встаёшь в семь?
```

- Знак препинания пишите прямо у последнего слова: `auf.`, `du?` — он станет отдельной плиткой.
- Слова одной строки с одинаковой основой — одна плитка. Если в следующем фрагменте та же строка (тот же номер) меняется, плитка переезжает на новое место: видно, как *in Leipzig* уходит на первую позицию, а *ich* — за глагол. Окончание после `+` может меняться: `wohn+e` → `wohn+st`.
- Заглавные буквы ставьте как в настоящем предложении.
- Поле «конец» и рамка между глаголом и концом показывают рамку предложения: отделяемая приставка, инфинитив после модального глагола, причастие в Perfekt.
- Схема особенно полезна, когда меняется порядок слов: вопрос, инверсия, отделяемые приставки, модальные глаголы, Perfekt.

### Часы — `view: clock`

`set: { view: clock, time: "07:30" }` — стрелки поворачиваются к новому времени, рядом официальное (*sieben Uhr dreißig*) и разговорное (*halb acht*) чтение со звуком. Обе формы считаются автоматически.

### Вопросы

```yaml
- question: Как спросить пожилую соседку, откуда она?
  read: >- ответ …
  point: …
  before: { … }   # необязательно: что показать, пока ответ закрыт
  set: { … }      # сцена после «Показать ответ»
```

Пока ответ закрыт, на сцене остаётся предыдущее состояние (или `before`). После нажатия сцена переходит в `set`. Поэтому `set` — это и есть ответ: подсвеченная строка таблицы, решённое задание (`solved: true`), новая строка схемы.

## Дело темы — `case`

Детективная история темы — глава сквозного дела уровня (см. [WORLD.md](WORLD.md)). Верный вывод на каждом шаге требует грамматики этой темы, а неверный ведёт по ложному следу с объяснением. Хорошая улика — та, которую «по-русски» прочитаешь неправильно: *sie kommen* — «они», а не «она», окончание падежа решает, кто кого видел, *halb acht* — это 7:30.

```yaml
case:
  title: Wo ist die «Sprotte»?     # по-немецки
  ru: Где «Шпротта»?
  intro: >- …                       # завязка, по-русски
  people:
    J: { name: Herr Jensen, voice: Grandpa, role: Hafenmeister }
  steps:
    - read: >- …                    # что происходит на этом шаге
      evidence:
        - J: Moin! Die Jolle ist weg.   # реплика свидетеля, озвучивается
          ru: Привет! Шлюпка пропала.   # перевод виден только после разгадки
        - note: |                      # записка, без озвучки
            Herr Jensen, …
          ru: …
      question: Сколько человек вышли в море?
      options: [Одна женщина, Двое или больше, Один мужчина]
      answer: 1
      right: >- …                    # что открывается после верного вывода
      wrong: [ …, null, … ]          # ложный след для каждого варианта (у верного — null) или один текст на все
  ending: >- …                       # развязка и крючок на следующую тему
```

Три-пять шагов. Перевод улик спрятан до разгадки, иначе он подсказывает ответ. Ложный след не ругает, а показывает, к какому неверному выводу привела ошибка и почему.

## Шпион — `spy`

Игра в тренажёре: четверо кильцев говорят по фразе, один — шпион, его выдаёт ошибка. Фразы с ошибками собираются автоматически из схем предложений темы: глагол не на второй позиции и чужое окончание глагола. В `spy` добавьте ошибки, которые автоматика не придумает: пропущенная связка (*Ich Dana*), страна без артикля (*aus Türkei*), неверная форма неправильного глагола.

```yaml
spy:
  - de: Ich bin Dana.
    wrong: Ich Dana.
    why: "Связку *sein* не пропускают: по-русски «я Дана», по-немецки *Ich bin Dana*."
```

Ошибка должна быть типичной для изучающих немецкий и ровно одна во фразе.

## Упражнения — `exercises`

```yaml
exercises:
  - type: choice
    q: ___ heißen Sie?          # немецкая строка с пропуском или русский вопрос
    options: [Wie, Wo, Woher]
    answer: 0                   # номер правильного варианта с нуля
    why: "*Wie heißen Sie?* — «Как вас зовут?»"
  - type: gap
    q: Du ___ aus Italien.      # один или несколько пропусков ___
    answer: [kommst]            # ответ на каждый пропуск; варианты через |
    hint: kommen                # подсказка в скобках
    ru: Ты из Италии.           # необязательный перевод
  - type: order
    ru: Ты говоришь по-немецки?  # задание
    de: Sprichst du Deutsch?     # правильный порядок
    also: [ … ]                  # другие верные порядки
```

В сборке фразы регистр не сравнивается: плитки даны, их можно только переставлять. Первое слово показывается со строчной буквы, если это служебное слово (*ich*, *jetzt*, *am* …) или если оно стоит со строчной в одном из вариантов `also`, а в собранной строке первая буква становится заглавной сама.

Хорошее упражнение проверяет одно правило темы. Смешивайте типы, давайте `why` там, где ошибка вероятна. Тренажёр артиклей и карточки слов собираются из `words` автоматически.

## Маршрут A1

Грамматика вводится строго по порядку. В теме можно использовать всё, что было раньше, и то, что вводится в ней самой.

| № | id | Тема | Новая грамматика | Экзамен |
|---|---|---|---|---|
| 1 | `kennenlernen` | Знакомство | личные местоимения, Präsens правильных глаголов, `sein`, W-вопросы и вопросы да/нет, глагол на второй позиции | sprechen-1, schreiben-1 |
| 2 | `zahlen` | Числа, алфавит, телефон | числа 0–1000, `haben`, вопросы да/нет и ответы ja/nein, алфавит и спеллинг | sprechen-1, hoeren-3, schreiben-1 |
| 3 | `familie` | Семья | притяжательные mein/dein/sein/ihr/unser/euer/Ihr (именительный), ein/eine и kein/keine, множественное число существительных | sprechen-2, lesen-1 |

| 5 | `einkaufen` | Покупки и одежда | цены и количества, личные местоимения в винительном (ihn, sie, es), welcher/welche/welches, прилагательное после sein (zu groß) | hoeren-2, lesen-2, sprechen-3 |
