# Moin · иллюстрации сцен

Сгенерированы встроенной генерацией изображений Codex CLI (OpenAI) по описаниям сцен прототипа
главы 1 (`src/story/scenes/01.ts`). 4 ноября 2026 года все картинки нарисованы или перерисованы по эталонам героев и
мест из `art/refs/` (приметы — `A1-ART.md`), чтобы герои и места совпадали от картинки к картинке. Общий стиль: плоская иллюстрация, приглушённая
северная палитра гавани с жёлтыми акцентами; текста на картинках нет, кроме слова MOIN.
Реальных людей, логотипов и брендов нет; Киль показан обобщённо. Исходные PNG сжаты в JPEG
1280×720 (`sips`, качество 55).
