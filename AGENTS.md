# Инструкции для LLM

Перед изменениями прочитайте `README.md`. Для редактирования учебного контента используйте `CONTENT.md`.

## Озвучка: принятое решение

Текущие 980 записей уже заменены на **Qwen3-TTS 1.7B**. Для дальнейшей генерации используйте **Qwen/Qwen3-TTS-12Hz-1.7B-Base**, лицензия **Apache 2.0**:
https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base

Системные голоса macOS и `/usr/bin/say` больше не используются. Не возвращайте их как запасной способ генерации и не описывайте текущую озвучку как черновую macOS-озвучку. Не меняйте выбранную модель без запроса пользователя.

- Полный процесс генерации, импорта и проверки: `scripts/tts/README.md`.
- Зафиксированные ревизии моделей, параметры, контрольные суммы образцов и проверенные варианты произношения: `scripts/tts/config.json`. Конфигурация входит в хэш URL аудио; сохраняйте этот механизм.
- Имена `Anna`, `Reed`, `Eddy`, `Sandy`, `Shelley`, `Rocko`, `Grandpa`, `Flo` — постоянные логические идентификаторы в YAML, а не используемые сейчас системные голоса. Их синтетические образцы находятся в `scripts/tts/voices/`, созданы Qwen3-TTS-1.7B-VoiceDesign (Apache 2.0).
- Готовые файлы: `public/audio/*.m4a`, mono 24 кГц, AAC 96 кбит/с. Обычная сборка переиспользует их и не запускает TTS. Не перегенерируйте аудио при изменениях интерфейса.
- Для новых фраз экспортируйте манифест через `scripts/build-content.mjs --audio-manifest`, генерируйте на GPU и импортируйте через `AUDIO_IMPORT_DIR`, следуя документации. Проверяйте произношение, особенно коротких слов и чисел, перед заменой файлов.
- Учётные данные SSH не копируйте в репозиторий и не выводите в логи. После удалённой генерации удаляйте созданные вами временные файлы, окружения и кэши; чужие процессы и данные не трогайте.

## Проверка изменений

Используйте `pnpm check` для проверки контента и `pnpm build` для сборки с проверкой TypeScript. После изменения контента или аудио убедитесь, что все ссылки из `src/generated/` ведут на существующие записи.
