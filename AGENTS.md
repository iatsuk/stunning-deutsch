# Инструкции для LLM

Автор учит немецкий сам, объясняя его другим; целевые уровни — telc A1, A2, B1. Перед изменениями прочитайте `README.md`.

Этот файл — индекс: здесь только правила для всего проекта. Правила области лежат в `AGENTS.md` её каталога, рядом `CLAUDE.md` из строки `@AGENTS.md`: Claude Code подгружает их сам, когда читает файлы каталога, Codex — когда работает внутри него. Перед правкой найдите в таблице «Куда смотреть» всё, что задевает изменение, включая сквозные случаи, и прочитайте указанные файлы. Каждое правило записано в одном файле; другие области на него ссылаются, а не копируют. Новая область — пара `AGENTS.md` + `CLAUDE.md` и строка в таблице; код области в другом каталоге получает только `CLAUDE.md` с импортом её файла. Структуру проверяет `scripts/agents.test.mjs`.

## Озвучка: принятое решение

**Решение автора от 26 октября 2026: для любой новой генерации использовать только OmniVoice** — `k2-fsa/OmniVoice`, ревизия и параметры в `scripts/tts/config.json`. Код Apache 2.0, предобученная модель CC-BY-NC; проект некоммерческий. Не запускать Qwen-TTS и не использовать системный синтез как запасной вариант.

Системные голоса macOS и `/usr/bin/say` больше не используются. Не возвращайте их как запасной способ генерации и не описывайте текущую озвучку как черновую macOS-озвучку. Не меняйте выбранную модель без запроса пользователя. Готовые записи, генерация и импорт — `scripts/tts/AGENTS.md`.

## Проверка изменений

Используйте `pnpm check` для проверки контента, `pnpm test` для проверки игровых ответов и `pnpm build` для сборки с проверкой TypeScript. После изменения контента или аудио убедитесь, что все ссылки из `src/generated/` ведут на существующие записи. `pnpm test` содержит проверки обоих сезонов и пробника. Проверяйте ссылки на аудио также в контрольных JSON, не только в темах.

## Общий браузер: сохранения автора

Встроенный браузер общий с автором: в его хранилище лежат настоящие сохранения (`sd-moin-story-v1`, `sd-moin-neu-v1`, `sd-progress-v1`, `sd-assessment-v1:*` и настройки `sd-moin-*`). Ключ `sd-moin-story-v1` — сохранение удалённой классической игры: код его не читает, но и он входит в копию. Тесты, которые меняют хранилище, начинайте с копии всех ключей `sd-*` и заканчивайте восстановлением ровно этого набора; тестовые сохранения поверх и `removeItem` без копии недопустимы. 1–3 ноября 2026 года тесты так стёрли прогресс основной игры.

## Секреты и инфраструктура

Файлы с ключами, паролями и данными доступа лежат вне репозитория. Не открывайте их для чтения и не выводите их содержимое: ни в ответах, ни в командах с видимыми аргументами, ни в логах. Если работа требует подключения, данные из файла доступа берёт скрипт и ничего из них не показывает. Не добавляйте в репозиторий сведения о частной инфраструктуре: IP и адреса серверов, хостинг генерации, имена пользователей, рабочие пути, пути к файлам доступа и SSH-псевдонимы. Открытые сведения о самом сайте, например публикация на GitHub Pages, к ним не относятся. Секреты не передавайте исполнителям-моделям. Чужие процессы и данные не трогайте.
